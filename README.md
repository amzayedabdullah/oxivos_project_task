# OXIVOS PROJECT TASK

A modern and responsive fashion e-commerce storefront built as part of the Oxivos Frontend Developer Hiring Process.


## How to Install & Use

```bash
git clone https://github.com/amzayedabdullah/oxivos_project_task.git

cd oxivos_project_task

npm install

npm run dev
```
